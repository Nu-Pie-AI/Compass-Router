# Support

For product issues, use the [Compass issue tracker](https://github.com/Nu-Pie-AI/Compass/issues) and include the extension version, VS Code version, operating system, and a sanitized description of the problem.

Do not include API keys, provider credentials, Clerk tokens, prompts, customer data, or `.env` contents in an issue.

For access, company membership, assigned Compass keys, project scope, or Credits questions, contact the administrator of your Compass workspace.
